# Préparation de la publication GitHub

Avant de rendre le dépôt public :

- [ ] Vérifier une dernière fois qu’aucun secret ou fichier personnel n’a été ajouté.
- [ ] Ajouter des captures d’écran anonymisées dans `docs/screenshots/`.
- [ ] Vérifier que le nom et la description du dépôt sont clairs.
- [ ] Garder `database/schema.sql` (structure seule) et ne pas ajouter le dump SQL original.
- [ ] Ne pas ajouter `vendor/`, les fichiers de diagnostic ou des fichiers téléversés depuis un compte réel.
- [ ] Ajouter une licence uniquement si vous choisissez explicitement les conditions de réutilisation du code.

Description suggérée :

> Application web PHP/MySQL de vente et de gestion d’articles artisanaux, avec espace client, administration, gestion de stock et factures PDF.

Topics suggérés : `php`, `mysql`, `pdo`, `bootstrap`, `e-commerce`, `inventory-management`, `portfolio`, `benin`.
